# مصادر أفق من GitHub

أي مصدر تضيفه بهذا المجلد يظهر **تلقائياً** داخل تطبيق أفق عند كل المستخدمين، وما يحتاج أحد يضيفه بيده.

## طريقتين للإضافة

### ١. رفع ملف JSON
1. افتح مجلد `sources` بالمستودع.
2. اضغط **Add file ← Upload files**.
3. اسحب ملف المصدر (`.json` بصيغة AltStore / ESign، اللي يحتوي قائمة `apps`).
4. اضغط **Commit changes**.

### ٢. إضافة رابط مصدر
1. افتح ملف `links.txt` واضغط على رمز القلم ✏️.
2. اكتب رابط المصدر بسطر جديد (رابط واحد بكل سطر).
3. اضغط **Commit changes**.

## شنو يصير بعدها
- خلال دقيقة تقريباً يتحدّث ملف `index.json` لحاله (لا تعدّل عليه بيدك).
- عند فتح التطبيق، أو سحب الشاشة لتحت بصفحة المصادر، تنضاف المصادر الجديدة.
- إذا حذفت ملف أو رابط من هنا، ينحذف من التطبيق تلقائياً.
- المصادر اللي يضيفها المستخدم بيده بالتطبيق ما تتأثر.
- إذا المستخدم حذف مصدر من هذي القائمة بيده، ما يرجع ينضاف عنده.
- رفع ملفات بهذا المجلد ما يبني نسخة جديدة من التطبيق.

## إذا ملف ما ظهر
افتح تبويب **Actions** ← **Update sources list** ← آخر تشغيل.
إذا الملف مو مصدر صحيح (JSON خربان أو ما بيه `apps`) راح تشوف رسالة تحذير باسمه، وينترك بدون ما يأثر على باقي المصادر.
