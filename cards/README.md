# بطاقات الصور بتبويب "اليوم" بتطبيق أفق

أي صورة ترفعها بهذا المجلد تظهر **تلقائياً** كبطاقة صورة كبيرة بين بطاقات التطبيقات بتبويب "اليوم"، عند كل المستخدمين.
بس صورة، بدون تطبيق تحتها. ما تحتاج نسخة جديدة من التطبيق.

(الصور اللي تتقلّب بأعلى الصفحة مكانها مجلد `banners`، مو هذا المجلد.)

## إضافة صورة
1. افتح مجلد `cards` بالمستودع.
2. اضغط **Add file ← Upload files**.
3. اسحب الصور (`jpg` أو `png` أو `webp`).
4. اضغط **Commit changes**.

- **الترتيب** حسب اسم الصورة: سمّها `1.jpg` و`2.jpg` و`3.jpg`… فتظهر بنفس الترتيب.
- **وين تظهر:** الصورة الأولى بعد أول بطاقة تطبيق، والثانية بعد البطاقة الرابعة، والثالثة بعد السابعة… وإذا زادت الصور على بطاقات التطبيقات تظهر الباقية بآخر الصفحة.
- **القياس المناسب:** صورة طولية بنسبة **4:5**، مثلاً **1080 × 1350**. البطاقة بنفس طول بطاقات التطبيقات، فممكن ينقص شوية من أطراف الصورة حسب حجم الشاشة. خلّي الكتابة والشي المهم بالنص، مو على الحواف.
- **الحجم:** الأفضل أقل من 1 ميغا حتى تظهر بسرعة على بيانات الهاتف.

## تبديل أو حذف صورة
- **تبديل:** ارفع الصورة الجديدة بنفس الاسم، وتتبدّل بالتطبيق.
- **حذف:** افتح الصورة واضغط على النقاط الثلاث ← **Delete file**.

## رابط عند الضغط على الصورة (اختياري)
افتح ملف `links.txt` بهذا المجلد واكتب بكل سطر اسم الصورة ثم الرابط، مثلاً:

```
1.jpg https://t.me/ofuq_store
```

الصورة اللي ما إلها رابط تبقى صورة بس.

## شنو يصير بعدها
- خلال دقيقة تقريباً يتحدّث ملف `index.json` لحاله (لا تعدّل عليه بيدك)، وGitHub يحتاج لحد ٥ دقائق حتى يوصل التحديث للتطبيق.
- الصور تتحدّث عند فتح التطبيق، أو عند سحب صفحة "اليوم" لتحت.
- إذا ماكو أي صورة بالمجلد، ما تظهر أي بطاقة صورة.

## إذا صورة ما ظهرت
افتح تبويب **Actions** ← **Update pictures lists** ← آخر تشغيل، وشوف إذا بيه تحذير باسم الصورة.
